# 🕹️ Arcade Pulse (v3.1)

A browser-based web arcade and indie game publishing platform where players compete on live leaderboards and creators submit HTML5 games to compete for a **₹500 Monthly Prize Pool**.

## ✨ Features

* **Built-In Playable Arcade:** Includes endless HTML5 Canvas mini-games (*Neon Runner: Overdrive*, *Cyber Pong Arena*, and *Space Defender 3000*) with instant browser play and mobile support.
* **Monthly ₹500 Prize Pool & Leaderboard:** Live ranking system that tracks verified plays and unlocks the ₹500 monthly reward pool once the minimum submission threshold is met.
* **5-Minute Active Playtime Anti-Cheat:** Enforces a strict 5-minute (`05:00`) active interaction timer with automatic idle-pause detection so plays only count when a user is genuinely playing.
* **Indie Game Submission & UPI Integration:** Creators can submit their own games via a ₹50 entry fee with dynamic UPI QR code generation and UTR transaction verification.
* **Single-File Architecture:** Runs as a lightweight, self-contained `index.html` application with zero external build steps required.

## 🚀 Live Access

1. Open the hosted GitHub Pages URL in any desktop or mobile browser.
2. Select any game card to launch the arcade modal and start playing.
3. Keep interacting with the game for at least **5 minutes** to register a verified play on the leaderboard.
4. Click **Submit Game** to enter your own HTML5 game into the monthly competition.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Cyber-Neon Glassmorphism UI), Vanilla JavaScript
* **Graphics:** HTML5 `<canvas>` 2D Game Engines
* **Hosting:** GitHub Pages
